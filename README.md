# TCP Socket Stream Parser & Receiver

This project is a network application developed using Python's `socket` library. It securely listens to a two-stage data stream (first 4000 bytes, followed by another 4000 bytes) over the TCP protocol and performs packet analysis on the first 49 bytes.
